■このゲームについて

 2Dシューティングゲーム



■起動方法

 フォルダ内の「Kadai1.exe」を実行してください


■基本操作

 Ｗ もしくは ↑キー：上移動
 Ａ もしくは ↓キー：左移動
 Ｓ もしくは ←キー：下移動
 Ｄ もしくは →キー：右移動

 Ｚ もしくは Spaceキー：攻撃

 Ｒ：プレイヤー撃破時に画面中央に復活


■このゲームの独自機能 (!!ここ大事!!)

◇プレイヤー追加機能

・プレイヤー画像を変更

・別の操作方法追加!!

・連射機能追加!!

・攻撃中、一定時間経過後に"拡散弾"が発射されるぞ!!
(拡散弾の仕様：敵撃破したときに敵を貫通する)

・拡散弾の見た目を緑色に変更

・敵に接触時に撃墜・復活が追加!!

・撃墜時に一時的無敵化するぞ!!

・無敵時に画像を変更


◇敵の追加要素

・敵の数が増加!!

・敵が斜めに動くぞ!!

・敵のダメージ演出が追加!!


◇その他追加機能

・BGMが再生されるぞ!!
